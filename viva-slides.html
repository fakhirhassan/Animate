The Gap

Creative AI is paywalled, fragmented, and cloud-locked.

Tools like Runway, Pika and Sora cost $20–$95/mo, run only in proprietary clouds, and force creators to jump between five different sites for video, voice, image and 3D. No single platform combines them — and none of them respect the creator's hardware.

✕

The Problem

• Subscription cost barrier (~$50/mo average)
• Tools are siloed: T2V, T2I, TTS, 3D — four products
• All processing happens on someone else's GPU
• Output is locked behind paywalls and watermarks

→

ANIAD's Answer

One unified pipeline: script → scenes → video → voice → 3D. Runs locally when hardware allows, transparently bursts to RunPod cloud GPU only when needed. Open-source models, no paid APIs, full creator ownership.

What ANIAD Does

Five generative pipelines, one platform.

Every feature is wired into the same auth, the same project store, and the same video timeline — so a creator can move from idea to finished animation without leaving the app.

▶

Animation Pipeline

System Architecture

Hybrid local + cloud, routed automatically.

A single backend decides, on every request, whether the work should run on the laptop's GPU or be sent to a cloud GPU. The user-facing app never knows the difference — it just gets results.

Step 02 · Understanding

A language model reads the story

A local large-language model (Llama 3.1) reads the script the way a director would — identifying distinct scenes, the subject of each, the setting, and the mood. It outputs a structured plan: a list of short, vivid prompts, one per clip.

Step 03 · Generation

A diffusion model paints each clip

Each scene prompt is fed to Wan2.1, a text-to-video diffusion model. It starts from random noise and, over many denoising steps, sculpts a short video that matches the prompt — frame by frame, consistent in motion and style.

Step 04 · Voice

A speech model narrates

In parallel, the same scene text is sent to Kokoro, a neural text-to-speech model. The user picks one of 23 voices; Kokoro produces studio-quality narration timed to match each clip's length.

Step 05 · Assembly

FFmpeg stitches everything together

All generated clips and matching narration tracks are handed to FFmpeg, the industry-standard video toolkit. It adds smooth crossfades between scenes, mixes the voiceover, and encodes the final MP4 — one continuous animated video out of many small parts.

Where it runs

The GPU question — solved automatically

Before generation begins, the backend checks what hardware it has. If the laptop's GPU is strong enough, the video is rendered locally — fast and free. If not, the same job is sent to a cloud GPU on demand. The user never has to choose.

FYP Contributions

What's new about ANIAD.

Each of these is a deliberate engineering decision the project's grade rests on — not features I copied from a tutorial.

01

Hybrid GPU Routing

One backend, two GPUs. Each request transparently picks the laptop's GPU or a remote cloud GPU based on the model's needs — the user never sees the difference.

02

Unified Creative Pipeline

T2V, T2I, TTS, 3D and scene parsing share the same auth, project model and history — competitors keep these as separate products.

03

No Paid APIs, No Watermarks

Every model is open: Wan2.1, SDXL, TRELLIS, Kokoro, llama3.1. Total ongoing cost ≈ $1–2 per full animation demo.

04

Production-Grade Hardening

12 bugs caught and fixed in a self-driven QA audit — auth bypasses, RLS gaps, silent FFmpeg failures, 401 reload loops. Selenium + pytest covering login, signup, voice, T2V and script parsing.
